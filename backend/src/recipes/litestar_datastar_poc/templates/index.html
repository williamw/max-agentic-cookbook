Litestar + Datastar

A simpler stack for AI-powered web apps

🚀 Litestar ⭐ Datastar 🤖 Claude/Llama 📡 SSE Streaming

Why This Stack?

  • Litestar: Simpler routing, built-in DI, better performance than FastAPI
  • Datastar: Reactive UI without React/Vue complexity
  • Less Code: No separate Pydantic models for every endpoint
  • SSE Streaming: Real-time updates with simple server-sent events
  • Hypermedia: Server renders HTML, client stays lean
