Litestar + Datastar Zero JS

A simpler stack for AI-powered web apps

🚀 Litestar ⭐ Datastar 🤖 Claude/Llama 📡 SSE Streaming

Why This Stack?

  • Litestar: Simpler routing, built-in DI, better performance than FastAPI
  • Datastar: Reactive UI without React/Vue complexity
  • Zero JavaScript: All reactivity is declarative via attributes
  • SSE Streaming: Real-time updates built into Datastar
  • Hypermedia: Server sends signals, Datastar updates the DOM
  • Less Code: This entire app is one backend file + one HTML file
