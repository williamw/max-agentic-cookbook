Why HTMX + Hyperscript?

  • HTMX: More mature than Datastar, widely adopted, great docs
  • Hyperscript: Readable scripting for small client-side behaviors
  • HTML-first: Server sends HTML fragments, not JSON
  • SSE Built-in: Native streaming support with hx-ext="sse"
  • Progressive Enhancement: Works without JS (degrades gracefully)
  • Battle-tested: Used in production by many companies
